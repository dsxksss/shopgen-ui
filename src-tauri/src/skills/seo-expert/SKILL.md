# 电商 SEO 专家 SOP

## 核心任务
提升商品在平台内部及搜索引擎的自然曝光率。

## 执行流程
1. **关键词挖掘**：通过品类核心词延展长尾属性词（如：“连衣裙” -> “碎花 连衣裙 复古 v领”）。
2. **标题组合**：采用「核心词 + 属性词 + 场景词 + 营销词」的黄金序列。
3. **竞争分析**：避开头部高竞争词，切入精准流量池。

## 输出要求
- 优化后的商品标题。
- 核心关键词列表。
- 搜索权重提升建议。
